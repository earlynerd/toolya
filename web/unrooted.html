The rooted screen-mirror needs natartos + ADB. This page is the no-root path: show the Goggles 3 live feed as an ordinary camera. It works once the feed reaches your OS as a camera device — it does not talk to the goggles itself. Why, and how to get there, below.

How Goggles 3 give video to a PC without root

Short version: not as a webcam. With wired sharing on, the goggles enumerate as a USB network adapter and serve the same UDP video session DJI Fly uses over Wi-Fi. A browser can't open that (no raw UDP, no USB-net), so a small native bridge on the host reads it — then re-exposes it as a virtual camera this page can show.

USB identity2ca3:0020 — RNDIS-style network adapter, not UVC. So getUserMedia never sees the goggles directly.
Host linkHost gets 192.168.60.1/24; goggles serve H.264 at 192.168.60.2:9003 (same session as DJI Fly). Needs a keep-alive; stream has no IDR, SPS/PPS repeat.
On the gogglesSettings → About → OTG Wired Connection to Computer on; then Share Liveview on (5D button). A live aircraft feed (or Camera View Recording) must be on screen.
Host privilegeConfiguring the USB-net adapter needs admin/sudo once; Windows also needs a one-time Zadig → WinUSB on interface MI 00. This is host admin, not goggles root.
What this means for the browser
  • UVC hypothesis — false. No webcam descriptor is exposed, so a pure-browser viewer can't capture the goggles over USB.
  • USB-net / UDP — out of browser reach. No raw sockets, no USB network class via WebUSB.
  • Reachable: any OS camera, including a virtual camera a bridge fills. That's what the viewer above uses — honest and root-free.

Get the feed into a virtual camera (no root)

  1. On the goggles: enable OTG Wired Connection and Share Liveview, with a camera feed on screen.
  2. Connect USB-C to the PC and run a native USB viewer — CosmoViewer Direct (macOS) or a community app (planktonwhc / Bruhkay; Windows needs a one-time Zadig → WinUSB on MI 00).
  3. Enable that app's virtual camera (CosmoViewer has one built in; otherwise route it through OBS → Virtual Camera).
  4. Back here: press Start, pick the virtual camera, Fullscreen.

Why a native app and not pure browser: the goggles speak USB-network (RNDIS), which WebUSB can't claim and the browser can't socket into — so a native helper reads the feed, the page shows it. See docs/unrooted-video.md.
